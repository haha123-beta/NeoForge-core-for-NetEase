# NeoCore 1.0.0：可信转换内核

创建者：haha123-beta、ChatGPT（OpenAI AI assistant）。项目自有代码采用 PolyForm Noncommercial 1.0.0；第三方代码遵守各自协议。

1.0.0 是可核对的工程里程碑，不代表所有 Java 模组可运行，也不将网易 SDK 替身测试称为网易实机验收。

## 固定对照

继续使用 0.9.8 的 14 个原始 JAR：其中 12 个 Java 样本共 369 个文件，一个零 Java 数据包，一个受版本守卫阻断的 26.3 样本。历史生成数为 53/369，0.9.9 为 58/369。比较单位是相同原件的生成结果；静态缺口频率、首阻断前移、生成文件、已执行能力、完整模组候选分别记录。

## 本版执行范围

- 优先修复已有提供者与编译器之间的合同，包括注册条目身份、只读集合视图、通用工厂目标推断、Java 数学特殊值、Integer.valueOf(int) 装箱与 Java 字符串返回值。
- 严格保持泛型不变性、声明边界、非法参数和版本守卫。只为已核查的 DeferredHolder 合同开放通配符读取，不将其泛化为可写容器的类型擦除。
- 保持 MiniCoal、FlintBlock vanilla 的资源、注册、放置/挖掘/掉落桥及卸载能力。实际引擎验收由用户完成。
- 不启动 GUI、Mixin、渲染器或完整网络专项。嵌套 record 试验确认还依赖整个嵌套类的所有权/导出，因此未发布不完整支持。
- 冻结后完整回归；保留失败日志。修改实现后重新验证，禁止用历史测试成绩代替本版验证。

## 交付原则

源码、核心 AddOn、最新源码加载器、协议说明、第三方许可及验收证据摘要一起交付。个人路径、账户、后端配置、原始模组、缓存和巨型工具链不上传。依赖与原件复用，历史证据不删除。

`verify_release.py` 核对相对路径、文件长度与 SHA-256，可用独立公布的清单哈希作为锚点。它只能证明包内字节一致性，不能替代代码审查、作者签名或游戏实测。

下一版本仍按真实共享阻断与修复收益排序。未通过端到端测试的 API 不以“已兼容”名义发布。
