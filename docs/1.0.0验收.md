## 本版完成的能力

| 能力 | 实际行为与约束 |
|---|---|
| DeferredHolder 条目身份 | `getKey()` 返回具体条目的 interned ResourceKey，而非注册表 key；同条目比较及哈希一致，跨注册表同名条目不同，比较不触发工厂求值。编译器返回类型保留 R。 |
| DeferredRegister 集合视图 | `getEntries()` 返回稳定、实时、保持插入顺序的只读 holder Set 视图，符合官方 LinkedHashMap keySet + unmodifiableSet；拒绝修改和 iterator.remove，迭代器检查结构变化。 |
| 有约束的通配符读取 | Collection.forEach 接通；仅对已核查的 DeferredHolder<R, ? extends R> 合同允许 lambda 读取，保留通配符身份。可写泛型容器、泛型不变性及非法赋值继续检查。 |
| 通用注册工厂 | 专用 Items/Blocks 的固定泛型父类关系被复用；一般 DeferredRegister.register 的 Supplier 结果和上下文目标按声明边界推断，保留 R/T 区分，不允许已有 holder 引用协变。 |
| Math.sqrt(double) | 接通已有提供者；负数返回 NaN，保留负零，覆盖 NaN、无穷、最小正数和最大有限值的 JDK 原始位对照。未开放未经验证的其他数学重载。 |
| Integer.valueOf(int) | 接通已有装箱提供者，验证缓存保证范围的引用身份、参数拆箱/拓宽、Number 传参和 null 拆箱异常。字符串解析及其他未审查重载继续阻断。 |
| ResourceLocation 字符串返回 | getPath/getNamespace/toString 的 Java String 返回值经过已有包装器，后续 length 等调用能连续执行。 |
| 可核对的源码交付 | 相对路径 SHA-256 清单、源码核验脚本、协议/创建者说明、独立核心 AddOn 和最新源码加载器。源码核验不等同于作者签名或网易实测。 |

## 交付与磁盘

运行 `py -3 verify_release.py` 检查当前源码字节；若有独立的清单 SHA-256，使用 `--manifest-sha256 HASH` 固定锚点。校验器拒绝非法/重复路径、丢失或改变的文件，保留用户本地配置和输出。

开发、原件复测、验证和发布目录位于 E 盘；复用原始 JAR、固定参考库、解析器及 Python 2 运行时，不复制整个 GB 级生态语料。失败/中止证据和旧版本均保留，未删除未经核查的历史文件。不能将其他进程造成的磁盘余量波动认作本版回收成果。

两轮已结束的中间原件证据共 81,756,832 字节，无损压缩后的文件数据占用为 50,141,737 字节，减少 31,615,095 字节（约 30 MiB），全文件哈希前后一致。这是文件数据占用测量，不是整个磁盘余量的原子差值。Git 属性保留源码原始行尾，避免检出时改变清单字节。

旧的独立 0.2.0 AddOn 加载器已在上一版从活跃 AddOn 目录移出并保留备份。本版源码包只带最新加载器。加载器内的 Mod.Binding 字符串与 AddOn manifest 的发布版本分开，不按字符串误删当前加载器。

## 保留的关键边界

- 外部 GUI/渲染泛型父类、RecipeBookMenu 运行时合同仍需证据与实现。
- 嵌套/局部 record 需要完整的类所有权与导出 lowering；试验未进入本版。通用网络 codec、Mixin、渲染专项未被包装为空壳兼容。
- Simple Online Command 主类实际含泛型网络 record、线程/网络依赖，不能因为仅三个类就认作只有简单命令桥。
- DuraTrack 仍涉及客户端事件、物品状态与耐久链；未声称已经完成实机耐久闭环。
- DeferredRegister.create 等未经核查的重载、Component.translatable、DeferredHolder 的其他方法继续严格守卫。
- 0.9.9 的受审查补丁目录保持原始哈希。历史升级方案遇到 1.0.0 已修改文件会拒绝基线不匹配，不会为了重放升级而覆盖新实现。
