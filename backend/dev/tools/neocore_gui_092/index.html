NeoCore 1.0.0 · 实际转换工作台
NeoForge JAR 由现有 CFR 准备 Java 源码，再交给现有转换器。支持的内容生成真实 Python、自动入口与 resources 布局，共用一份独立核心。
不支持的语法、Mixin、声明或嵌套依赖会报告阻断。原 JAR 只复制读取，不执行；assets/data 仅保留。成功状态为待审查，不是网易玩法通过。
当前连接本机开发工具，需要 Python、已有 JDK/CFR 与转换器；尚非免环境 EXE。关闭页面后后台任务继续，重新启动可查看；使用退出工具正常停止服务。
